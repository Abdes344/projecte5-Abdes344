# 🚀 P01: Control de Versions amb GitHub Classroom i Git

## 📖 Breu descripció

Al llarg dels diferents projectes que hem anat treballant, **GitHub** ha esdevingut l'espai on presentem la documentació dels nostres projectes. Tot i que fins ara hem lliurat diverses activitats directament des de la web, aquest mètode presenta alguns inconvenients:

- 🐌 És més lent a l'hora de crear carpetes i fitxers.
- 🖼️ Penjar imatges i organitzar continguts pot resultar incòmode.
- ⚙️ No aprofitem totes les funcionalitats del control de versions.

Per aquest motiu, en aquest projecte farem un pas més en el món del **control de versions**. A partir d'ara:

- 💻 Treballarem principalment en local.
- 📝 Farem seguiment dels canvis utilitzant **Git**.
- ☁️ Sincronitzarem els nostres repositoris locals amb **GitHub**.

---

## 🔒 Repositoris privats i seguretat

Fins ara, els repositoris eren públics, fet que permetia que qualsevol persona pogués veure el nostre treball. Això pot generar problemes si algú decideix aprofitar-se de la feina d'altres persones.

Per solucionar-ho, utilitzarem **repositoris privats**, que ofereixen:

- 👀 Visibilitat només per als usuaris autoritzats.
- 🔐 Major confidencialitat del projecte.
- 🛡️ Protecció del treball realitzat.

---

## 🎓 Què és GitHub Classroom?

Treballarem amb **GitHub Classroom**, una plataforma orientada a l'àmbit educatiu que proporciona una estructura similar a la de les organitzacions professionals.

### Característiques principals

- 🏢 Els repositoris són propietat de l'organització.
- 🔄 Cada alumne rep automàticament una còpia (*fork*) del repositori base.
- 👤 Cada estudiant treballa en el seu propi repositori privat.
- 🤝 El professorat pot supervisar i avaluar el treball de manera centralitzada.

Més endavant, aquests repositoris podran passar a ser públics 🌍, cosa que permetrà:

- 📂 Fer un *fork* al compte personal de GitHub.
- 💼 Afegir el projecte al portafoli professional.
- ⭐ Mostrar la feina realitzada a futures empreses o col·laboradors.

---

## 🎯 Objectius del projecte

- Aprendre els conceptes bàsics de **Git**.
- Utilitzar **GitHub Classroom** per gestionar repositoris.
- Realitzar canvis en local i sincronitzar-los amb GitHub.
- Entendre la importància del control de versions.
- Treballar amb repositoris privats de forma segura.
